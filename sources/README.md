# Primary Source Scans

Run `../scripts/fetch-sources.sh` from any directory to download the two
Sketchpad listing scans and the November 1963 TX-2 Users Handbook.  The
script uses URLs pinned to Computer History Museum repository commit
`31425aaad4268b6b225409b1e1b21c5c8076a0a6`.  It downloads the handbook
from Internet Archive item `tx-2-users-handbook-nov-63`.

The PDF files are ignored by Git.  `SHA256SUMS` identifies the exact local
copies used for reconstruction.

The Computer History Museum repository states that its images and content
cannot be used commercially without written permission.  The Internet
Archive item does not state a license.  Do not publish or redistribute the
PDF files from this repository.
