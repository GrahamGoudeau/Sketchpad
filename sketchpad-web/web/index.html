Operator guide

Use the real Sketchpad input path

  1. Position the pen. Move the pointer anywhere over the scope. The browser continuously sends that position to the emulated light-pen hardware.
  2. Engage the sensor. Click once on a bright part of INK. The original photocell cannot detect blank glass. Wait until Light pen says TRACKING. Press Escape when you want to disengage the sensor.
  3. Draw. Hold D to send Q1.8 STARTDRAW. Move the tracker without holding the mouse button. Release D. The browser then holds Q1.6 STOPMOVEP. The original assembly finalizes the line. The next D press releases Q1.6 before it sends Q1.8 again.
  4. Select. Move over the middle of a visible line. Click once if the sensor is disengaged. Wait until Selection says LINE. Send the next command while the sensor remains engaged.
  5. True up and solve. Leave Solve off. Tap T once. This sends Q2.9 to TRUEUP. The assembly adds one horizontal-or-vertical constraint. Then turn on Solve. The original RELAX routine changes the endpoints.
  6. Fix and release. Select an object. Tap F once. FIXIT puts it in the original fixed-object list. U runs UNFIX and clears the fixed and designated lists.

Light pen now reports the assembly's own LPLOST state. Unit 55 reports only an optical hit. It does not report coordinates. A fast jump can outrun the original tracker search pattern and show LOST. Move back across a bright tracker mark to reacquire it. A larger Pickup radius models a more permissive detector.

The short perpendicular stroke at a moving endpoint can be the original tracker search pattern. Use Visual diagnostic log when a discontinuity does not look like that pattern. Stop the recorder, download the WebM file, and attach it to the project report.

Input handler measures browser work from one pointer event to publication of the physical pen state. Pen apply measures transfer of that state into the worker-owned emulator. The visible tracking marks still follow the original assembly and scope timing.

The Q4-Q1 panel remains available for every external-input bit. Named buttons come from the recovered READIT dispatch table. Keyboard shortcuts only press those emulated physical buttons. They do not create or edit geometry in JavaScript.
