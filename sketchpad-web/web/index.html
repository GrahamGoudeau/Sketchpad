Operator guide

Use the real Sketchpad input path

  1. Draw. Hold the mouse on the scope. Press D to send external button Q1.8. Drag the light pen. The assembly creates the points and line.
  2. Select. Hold the light pen over a visible line. Wait for the assembly-drawn tracking marks to settle on it.
  3. Constrain. Press T to send Q2.9, the recovered TRUEUP command. The assembly creates a horizontal-or-vertical constraint.
  4. Solve. Turn on Solve after the constraint exists. This sets the metabit of register 377720. The original RELAX routine changes the geometry.

The Q4-Q1 panel remains available for every recovered external-input bit. Keyboard shortcuts only press those emulated physical buttons. They do not create or edit geometry in JavaScript.
